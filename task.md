Во многих окружениях награда зависит от числа шагов. Это делает окружение не марковским (или в состояние нужно добавлять номер шага). Чтобы упростить работу, примените обертку, преобразующую награду в бинарный формат:
```
class BinaryRewardWrapper(Wrapper):
    def step(self, action):
        observation, reward, terminated, truncated, info = self.env.step(action)
        bin_reward = 1 if reward != 0 else 0
        return observation, bin_reward, terminated, truncated, info
```

6. On-policy learning and SARSA. Expected Value SARSA for softmax policy
Алгоритм Q-learning при обновлении Q-значения использует наилучшее действие (100% жадный off-policy подход). При этом он использует данные, собранные другой, более исследовательской ε-жадной политикой, которая выбирает лучшее действие только с вероятностью 1-ε. Это может привести к тому, что Q-learning будет переоценивать ценность действий, ведущих через "опасные" состояния, если оптимальный путь через них существует. В реальном выполнении с исследовательской политикой агент может часто падать в эти опасные состояния, получая большие штрафы, и в итоге не добираясь до конца уровня.
